# Blog Application

Blog Application made with Express.js, React, MySql

- Utilizes JSONWeb Token for Auth.
- Utilizes Rich Text Editor
- Organizes Posts into Categories

## Installation

Navigate to both of the directories backend and client

Now Install the dependencies

```
npm install
```

## Running the Application

Stay in both of the terminals and execute:
`npm start`
